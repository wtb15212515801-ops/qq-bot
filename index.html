这个网页是什么

真机版跑在 Windows 上：NapCat 把 QQ 客户端包成 OneBot 接口，Node.js 收消息、决定回不回，再调大模型。
  • 网页没法接管 QQ，所以这里是同一个脑子，换了个壳
  • 不填 Key → 演示模式，脚本回复，断网可用
  • 填自己的 Key → 真的调 api.deepseek.com，不开代理
  • Key 只存在你自己的浏览器里，不会上传
源码：github.com/wtb15212515801-ops/qq-bot
